## 📋 À propos du Projet

**GestionBibliotheque** est une application de bureau développée en **C#** permettant de gérer efficacement une bibliothèque (livres, adhérents, emprunts, retours, etc.).

### ✨ Fonctionnalités principales

- Gestion des **Livres** (ajout, modification, suppression, recherche)
- Gestion des **Adhérents** (inscription, informations personnelles)
- Gestion des **Emprunts** et **Retours**
- Historique des transactions
- Recherche avancée (par titre, auteur, ISBN, etc.)
- Interface conviviale avec Windows Forms / WPF

---

## 🛠️ Technologies utilisées

- **Langage** : C# 
- **Framework** : .NET (Windows Forms ou WPF)
- **Base de données** : MySQL
- **IDE** : Visual Studio / Visual Studio Code
